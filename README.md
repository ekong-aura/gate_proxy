VPN Gate 家宽落地与自动化可视化控制面板 (gate_proxy)一套基于甲骨文（Oracle Cloud）或其他海外 VPS 的全自动化家庭宽带（Residential IP）落地代理解决方案。将全球学术志愿者网络（VPN Gate）与现代代理协议（SOCKS5 / Shadowsocks）深度结合，并配备轻量级 Web 控制面板与智能断线自愈守护进程。🌟 核心特性🛡️ 零失联防护设计：OpenVPN 强制注入 --route-noexec 与 --route-nopull，绝不修改 VPS 主网卡默认路由，彻底杜绝 SSH 掉线与失联风险。🔌 双协议隔离输出：SOCKS5（端口 10808）：专为软路由（OpenWrt / ShellCrash / sing-box）链式代理设计，通过前置机场加密穿透。Shadowsocks（端口 10809）：aes-256-gcm 军工级加密，生成标准 Base64 链接，支持客户端（小火箭 / Clash / v2rayN）直接导入使用或软路由直连。🤖 智能双模看门狗（Auto-Failover）：自动保活模式：后台轻量守护进程默认每 30 秒巡检出网状态，断线时自动按多级优先级（日本 JP $\rightarrow$ 韩国 KR $\rightarrow$ 美国 US）秒级故障转移。手动锁定模式：在面板手动指定连接某个节点时，系统自动切入锁定状态，绝不跨国强行切线，尊重用户单点业务需求。📊 可视化管理面板（端口 5000）：内置官方节点库动态拉取、全量国家分类统计、延迟/带宽/评分排序、分页浏览与实时存活探测。🔐 动态强凭据：每次安装均在本地生成随机独立的强密码，并将配置清单留底存储在服务器本地。📋 运行环境要求操作系统：Ubuntu 20.04 / 22.04 / 24.04 LTS 或 Debian 11 / 12（兼容 x86_64 及 ARM64 架构）。权限：具有 root 或 sudo 权限。安全组/防火墙：请提前在云服务器后台（如甲骨文云 VCN 安全列表 Ingress Rules）放行以下 TCP 入站端口：5000（Web 控制面板）10808（SOCKS5 代理端口）10809（Shadowsocks 代理端口）🚀 快速开始1. 一键全自动安装登录 VPS 终端，复制并执行以下命令：Bash
